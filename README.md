### 📖 Tentang Repositori

Repositori ini berfungsi sebagai ruang kerja (*workspace*) dan repositori resmi untuk pengembangan **Sistem Manajemen Pesantren Multi-Client Berbasis Web**. Sistem ini dirancang untuk memungkinkan banyak pesantren menggunakan satu instans aplikasi dengan pemisahan data yang aman (*multi-tenant*).

**Keterangan Pengembangan:**

* Proyek ini dikembangkan menggunakan **Laravel 13** dan basis data **MariaDB**.
* Setiap laporan, *source code*, dan dokumen spesifikasi (SRS) dikelola secara terpusat di dalam repositori ini.
* Riwayat pengerjaan dan perubahan fitur dikelola secara inkremental menggunakan sistem *version control* Git.
